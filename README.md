# Ritmo

PWA para seguir um protocolo diário de longevidade, nutrição e desempenho: checklist por blocos horários, temporizador de jejum 16:8, agachamentos por hora, registo de GtG com kettlebell, aeróbio semanal, histórico e grau de evidência por item.

Dados guardados apenas no dispositivo (localStorage). Usa Exportar/Importar backup nas Definições.

App: https://possn.github.io/ritmo/
